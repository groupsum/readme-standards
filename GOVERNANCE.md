# Governance

Groupsum maintains this project. Propose changes through an issue or pull request;
maintainers review implementation, documentation, tests, and compatibility before merging.

The package-guide-v1 heading tree is a versioned public contract. Changing required
labels, order, levels, or content ownership requires a new policy identifier and migration
documentation. Fixes to parsing or diagnostics require regression tests.

The renderer owns only marked generated regions. Authored prose belongs to contributors
and must never be silently discarded. Ambiguous repair stops for manual resolution.

Certification and evidence claims must describe what was checked. Passing structural
validation does not establish prose quality, runtime correctness, or external certification.

The default branch is master. CI is required by project policy before release; this
statement does not claim that GitHub branch protection has been configured.
